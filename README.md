# Orbit 表盘作品集

用于「轻腕社区 · 成为开发者」申请的作品集。

## 内容
- `index.html` —— 作品集首页（3 款表盘 + 交互预览）
- `faces/<slug>/preview.png` —— 商店用的 466×466 预览图
- `faces/<slug>/preview.html` —— 可交互演示（指针实时走动）
- `faces/<slug>/src/watchXXXX/assets/` —— 表盘实际使用的图片资源

## 怎么变成「作品集链接」
把整个 portfolio 文件夹上传到任意一个公开可访问的地方，文档里明确接受：
- GitHub Pages / Gitee Pages / GitCode
- 或任何「打开就能看」的网站链接

> 官方要求原文：链接内需包含已完成的应用或表盘，以及对应的预览图；请勿填写网盘链接。

## 用 GitHub Pages 的最短路径
1. 新建仓库（Public），把本文件夹内容推上去
2. Settings → Pages → Source 选 `main` / root → 保存
3. 等 1 分钟，得到 `https://<用户名>.github.io/<仓库名>/`
4. 把这个链接填进轻腕社区的「作品集链接」
